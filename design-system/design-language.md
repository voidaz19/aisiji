# 设计语言

## 一句话定义

爱思记是“安静的纸面书写空间”：以白纸、文楷、墨绿和低对比层次减少工具感，让笔记内容、而非界面容器，始终成为视觉重心。

## 视觉原则

### 纸面优先

- 默认背景、主 surface 与编辑画布均接近纯白；夜间模式转为低饱和深绿黑，而不是纯黑。
- 页面用留白、微弱分隔和层级来组织，不用大面积边框或高对比色块切割内容。
- 内容区保持单一、连续的阅读面；编辑器不套卡片，卡片只服务于设置、菜单和短暂浮层。

### 柔和而明确的层级

- 常驻白色控件不用描边；浅色模式以低透明度、均匀扩散的 `soft` 阴影分层。
- 圆角只使用 8 / 12 / 18 / 24 / 30 五档。短控件多用 12 或 18，卡片与菜单多用 24，搜索和主要行动可用胶囊。
- 浮层的层级只在需要脱离阅读流时出现：上下文菜单、工具条、确认操作和设置卡片。

### 有节制的自然色

| 角色 | 日间值 | 用途 |
|---|---:|---|
| 墨色 `ink` | `#2D332E` | 正文、标题和主要图标；避免纯黑。 |
| 叶绿 `leaf` | `#4F7D68` | 主按钮、链接、当前项、焦点与进度。 |
| 淡叶绿 `leaf-soft` | `#DCE9DD` | 选中容器、弱强调背景。 |
| 金色 `gold` | `#D2A448` | 置顶、次级强调和温暖提示。 |
| 陶土色 `clay` | `#D77A61` | 错误与不可逆操作；只用于需要用户注意的地方。 |
| 雾面 `surface-muted` | `#F7F7F5` | 输入、悬浮、弱分组与空状态。 |

颜色必须表达语义而非装饰：绿色不是所有按钮的填充背景，金色不用于普通文本，陶土色仅用于错误/删除。深色模式的实际数值按平台不同，不能直接从日间色反相推导。

## 字体与内容密度

- 品牌与正文首选 LXGW WenKai（霞鹜文楷）。Android 通过字体资源注册 light / regular / medium；Web 与 Android 编辑器提供对应回退字体。
- 正文依赖字形、行距和留白建立阅读节奏；不要用粗边框、过度加粗或压缩行距来“增强层级”。
- Markdown 编辑器正文为 16px、1.72 行高；一级、二级、三级标题为 28 / 24 / 20px，粗体使用 700 或 800。
- 代码、表格和错误文本使用系统等宽字体；其余内容仍使用文楷，避免混用无衬线 UI 字体。

## 交互状态

- 静止态克制：弱表面、常规墨色、无明显边框。
- 悬停/聚焦态先提升文字对比或切换到雾面 surface，再增加阴影；不使用突兀的缩放和高饱和填充。
- 当前/选中态使用淡叶绿背景或 3px 叶绿侧标，保留文字可读性。
- 主要行动使用叶绿实底和浅色文字；危险操作以陶土/错误色标识，并在删除前提供明确确认。
- 动效采用 `150ms` / `220ms` 与 `cubic-bezier(0.2, 0.8, 0.2, 1)`；弹层进入 140ms、退出 40ms。系统请求减少动态效果时，弹层动画必须关闭。

## 可访问性与响应式约束

- 主要触控操作的最小尺寸是 44px；图标操作应有可理解的文本或无障碍标签。
- 颜色不是唯一状态信息：选中项同时有背景/侧标，危险操作同时有文字和确认流程。
- 桌面端在 1080px 前先收紧编辑器行动区，在 860px 以下把侧栏改为覆盖层；编辑内容仍保持可用宽度。
- 文字、长标题、笔记预览必须可以截断或换行，不能依赖固定英文长度。

## 明确不属于默认风格

- `DebugThemeSettingsCard` 的“暖纸”“橄榄”预设是调试主题，不是默认配色。
- CodeMirror benchmark 的内联样式仅用于性能基准，不是应用组件规范。
- Android 的 `res/values/colors.xml` 是系统主题/遗留资源，不是 Compose 设计令牌来源。
