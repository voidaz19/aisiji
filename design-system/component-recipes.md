# 组件配方

本页只记录已有产品组件的稳定视觉组合。新增功能应优先复用这些配方和语义角色，而不是复制某个页面的局部参数。

## 通用配方

| 组件 | 结构 | 视觉规则 | 已有实现 |
|---|---|---|---|
| 主要按钮 | 图标可选 + 短文本 | 44px 及以上触控面；叶绿实底、浅色文字、18–24 圆角；轻阴影只在浮于内容时使用。 | Android 首页新建；桌面 `.asj-button--accent`。 |
| 次级/图标按钮 | 单图标或短文字 | 透明或雾面背景；悬停才显著；不默认使用描边。 | Android 编辑器工具栏；桌面 `.asj-button`。 |
| 输入/搜索胶囊 | 图标 + 输入 + 可选清除 | 白色/雾面 surface、18–24 圆角、软阴影；焦点使用叶绿相关提示。 | `HomeHeader`；桌面 `.search-box`。 |
| 设置卡片 | 标题、说明、控制项 | 近白 surface 约 0.98 alpha、24 圆角、无 elevation、`softShadow`；卡片内 16–18dp 横向边距。 | `*SettingsCard.kt`。 |
| 菜单/弹层 | 操作列表，可分区 | raised surface、24 圆角、`soft-lg` 阴影；操作行 34–36px；从锚点缩放淡入。 | `HomeNoteContextMenu`；桌面 `.note-row-menu` / `.more-menu__panel`。 |
| 删除确认 | 文案 + 取消 + 确认 | 与普通菜单分隔；确认按钮使用错误/陶土色，避免把危险操作伪装为主行动。 | Android 上下文菜单；桌面 `.delete-confirm`。 |

## 首页与列表

- 首页是全幅纸面，不使用大卡片包裹列表。
- 顶部使用搜索胶囊作为主要工具入口；新建操作可使用叶绿圆形/胶囊按钮。
- 笔记列表项以文本为主：标题优先、预览和元信息降为 `ink-muted`；当前项用低透明叶绿和叶绿侧标，而不是整行高饱和填充。
- 置顶使用金色，词语收集使用 tertiary/绿色；删除必须保留危险色。
- 空状态在雾面容器里给出一句说明和一个主要行动，避免多余插画干扰书写产品的克制感。

## 编辑器

### Android

- 编辑页面是背景色上的连续内容面：顶部返回、居中标题和操作区保持轻量；正文区不再加卡片或边框。
- 原生 Markdown 工具栏是浮于底部/内容边缘的白色圆角 surface，使用 `softShadow`，按钮间距紧凑但点击面独立。
- CodeMirror WebView 本身只负责正文编辑；宿主的标题栏和工具条继续遵守 Android Compose 主题。
- 词语收集是唯一允许更强“物件感”的编辑模式：词条气泡可用 `secondaryContainer`、圆形/胶囊形态与柔和阴影，但不应扩散到普通 Markdown 页面。

### 桌面/Electron

- 桌面固定三栏：46px library rail、312px sidebar、主编辑区；窗口标题栏 44px。
- 编辑区顶部为轻分隔的标题栏，正文最大宽度 860px 并居中，保留宽松左右留白。
- 浮动格式工具条、更多菜单与笔记行菜单统一使用 raised surface、24px 圆角和 `soft-lg` 阴影。
- 低于 860px 时侧栏覆盖内容区，不能把编辑器压缩为不可读的窄列。

## Markdown 内容表现

| 内容 | 规则 |
|---|---|
| 标题 | 28 / 24 / 20px 三档，700 粗细，源码标记回露时使用弱墨色。 |
| 引用 | 低透明叶绿背景、3px 叶绿引导线、12px 圆角；多行中间不重复圆角。 |
| 任务 | 低透明叶绿底，18px 自定义勾选框；完成态用细删除线过渡。 |
| 代码 | 等宽字体、低对比冷灰/深色 surface；块级代码采用 8px 圆角。 |
| 表格/流程图 | 有限宽度的可横向滚动 surface，细叶绿透明分隔；不能因外边距破坏编辑器行高测量。 |
| 数学/高亮 | 低透明金色背景；错误文本使用陶土色系。 |
| 链接/标签 | 叶绿、细下划线或中等字重；不是蓝色浏览器默认样式。 |
| 图片 | 最大宽度受正文约束，8px 圆角，阴影比浮层更弱。 |

## 禁止项

- 不新增未命名的近似绿色、灰色或圆角值。
- 不把普通阅读/编辑内容塞进高阴影卡片。
- 不在同一交互层级同时使用粗描边、强阴影和高饱和背景。
- 不把桌面 hover 效果当作 Android 的必要反馈；移动端应依赖按压、选中与可访问性状态。
