# Canvas Supertag SPEC

状态：首版已确认。

## 定义

`Canvas` 是附着于内容节点的内建 supertag，不是节点种类、独立页面或第二套树。节点保留原有 ID、Markdown、父子关系、排序、删除恢复、搜索与同步操作语义；一个节点可同时拥有多个 supertag。

## 首版行为

- 对任意内容节点应用 `Canvas` 后，打开该节点时显示 Canvas 视图。
- 带 `Canvas` 的节点出现在普通节点树中且处于展开状态时，保留节点标题行，并在标题行下方局部显示直接子节点卡片；折叠后隐藏局部 Canvas。
- 局部 Canvas 作为父节点的可见子树保留层级线，线条从父节点延伸至网格底部；点击或键盘激活该线可折叠局部 Canvas。
- 局部 Canvas 取代该节点的普通可见子树：直接子节点不重复显示为树行，更深后代在进入对应卡片节点后查看。搜索和回收站仍按普通行展示，不启用局部 Canvas。
- Canvas 以稳定的响应式自动网格显示该节点的直接子节点；卡片顺序严格复用树的 `sortKey` 顺序。
- 同一网格行内的卡片等高，避免短卡片下方形成伪行间距；响应式换行后只在各自行内对齐，不强制所有卡片使用统一高度。
- 卡片中的 Markdown 可直接编辑；新建卡片等价于创建一个普通直接子节点。
- 进入子节点后，仍沿用普通页面或其自身的 Canvas 视图。
- 移除标签只退出 Canvas 视图，绝不删除或转换子节点。

## 非目标

首版不提供自由卡片、画布内坐标、连线、拖拽定位、独立画布文件或 Canvas 专属持久化字段。以后若引入这些能力，必须另行确认数据模型、操作日志和同步冲突规则。

## 数据与操作

- 节点以 `NodeRecord.supertagIds` 保存稳定标签 ID；`canvas` 是当前唯一内建标签定义。
- 应用、移除标签会作为普通节点更新增加 revision，并各写入一条操作日志。
- 当前持久化会随节点快照保存此元数据；增量持久化实施时应将其纳入节点实体。
